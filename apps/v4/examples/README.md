# Examples

This directory contains demo components for the component documentation.

## Directory Structure

```
examples
├── base
│   ├── button
│   │   ├── button-demo.tsx
│   │   └── button-loading.tsx
│   └── ...
├── radix
│   └── ...
├── aria
│   └── ...
└── __index__.tsx    # Auto-generated by registry:build
```

Demos are grouped by component (or related category) so each base is not a
single flat folder of hundreds of files.

## Adding a New Example

1. Create a new `.tsx` file in the matching component folder under
   `examples/base`, `examples/radix`, or `examples/aria`:

```tsx
// examples/base/button/button-loading.tsx
import { Button } from "@/styles/base-nova/ui/button"

export function ButtonLoading() {
  return <Button disabled>Loading...</Button>
}
```

2. Run the registry build to regenerate the index:

```bash
pnpm --filter=v4 registry:build
```

3. Use the example in documentation by referencing its **filename** without
   `.tsx` (the folder is not part of the name):

```tsx
<ComponentPreview name="button-loading" />
```

## Notes

- Place example files in a component folder, e.g. `examples/base/button/button-demo.tsx`.
- Nested paths are allowed; the public example name is always the basename.
- Filenames must stay unique within a base. `button/demo.tsx` and `card/demo.tsx` would collide.
- Base examples should import from `@/styles/base-nova/*`. Radix examples should import from `@/styles/radix-nova/*`.
- Both named exports and default exports are supported.
- After adding or removing examples, run `pnpm --filter=v4 registry:build` to update the index.
